Privacy Policy — Flip & Spill

Last Updated: April 2025

1. No Personal Data Collection

The Flip & Spill application does not collect, store, or transmit any personal data to any server or third-party service. All data remains exclusively on the user's device.

2. Local Storage Only

Player names entered by users are stored exclusively using Hive — a local on-device database. There is no cloud synchronization, no Firebase, and no backend server.

3. No Account Required

The application does not require any registration, login, or email collection of any kind.

4. No Analytics

The application does not use Firebase Analytics, Google Analytics, Mixpanel, or any equivalent tracking SDK.

5. Advertising (Google AdMob)

The application uses Google AdMob for displaying banner and interstitial advertisements. AdMob may collect certain device identifiers for ad personalization as per Google's own privacy policy. The developer does not have direct access to this AdMob data. For more information, please refer to Google's Privacy Policy.

6. Device Permissions

The application does not request or use camera, microphone, GPS, or location permissions.

7. Data Deletion

Since all data is stored locally on the device, users can delete all data by uninstalling the application from their device.

8. Children's Privacy

This application is rated for users aged 13 and above and is not directed at children under the age of 13.

9. Contact

For any questions regarding this privacy policy, please contact us through the in-app settings menu.
